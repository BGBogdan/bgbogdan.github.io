PA database app

A private connection between Claude and a Google BigQuery database.

What it does

PA database app lets people who have been given access connect Claude, Anthropic's AI assistant, to a Google BigQuery database. They can then ask questions about the data in plain language, and Claude runs the queries needed to answer them.

Read-only access

The Google account used with this app can only read data. It cannot create, change or delete anything in the database.

Who can use it

This is a private tool, not a public service. Signing in only works for accounts that have been given access to the database in Google Cloud.
